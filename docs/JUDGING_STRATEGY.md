# Hackathon judging strategy

## One-sentence pitch
**CountryLab turns a webpage into a shared experimental world where a human can change an economy and an agent can inspect, manipulate, and scientifically test explanations through WebMCP.**

## What judges must see
1. Human changes live page state manually.
2. Agent discovers semantic WebMCP tools instead of clicking UI blindly.
3. Agent reads the human's updated state.
4. Agent changes/highlights the same world.
5. Agent runs a counterfactual without destroying the live world.
6. Human interrupts/changes something and agent adapts.

## Avoid in demo
- Long explanation of economic equations.
- Generic chatbot conversation.
- Showing 30 tools just for quantity.
- Claiming economic realism/prediction.
- Spending time on settings/auth/backend.

## Submission framing
The innovation is not “an economics game with AI.”
It is **interactive websites as experimental instruments for human-agent reasoning**. Economics is the memorable domain that makes that interaction visible.
