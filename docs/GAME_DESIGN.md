# Game design

## Player fantasy
“You are running a tiny country. Every choice has consequences. Break things on purpose, then understand why the economy reacted.”

## Core loop
1. Observe the country.
2. Change one policy or trigger one shock.
3. Advance time.
4. See visual + metric consequences.
5. Ask the agent “why?”
6. Agent inspects live state/history.
7. Ask “prove it.”
8. Agent runs a controlled counterfactual.
9. Compare outcomes.

## Regions
- **Capital** — services, government, demand
- **Farmbelt** — food supply
- **Industrial** — manufacturing/jobs/exports
- **Port** — imports/exports
- **Energy** — power/oil exposure

## Shocks
- Flood → port/trade + production disruption
- Drought → food supply shock
- Conflict → production/trade/confidence shock
- Oil shock → energy + production-cost shock

## Tone
Strategy game, not textbook dashboard. Visually charming, legible, and slightly playful. Keep explanations rigorous but concise.
